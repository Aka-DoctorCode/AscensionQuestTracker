# Ascension Quest Tracker

## **Work in progress**

***

**Ascension Quest Tracker** is a high-performance, minimalist replacement for the default World of Warcraft objective tracker. This addon streamlines the questing experience by removing clutter while providing deep integration with modern game features.

***

## Core Features

* **Minimalist Design**: A clean, non-intrusive UI that replaces the bulky default tracker with a sleek, organized list.
* **Intelligent Sorting**: Quests are automatically sorted by proximity, ensuring that the objectives closest to your current location are always at the top.
* **Super Track Integration**: Full support for the native "Super Track" focus system, featuring distinct visual highlighting for your primary objective.
* **Modular Organization**: Objectives are separated into logical categories:
* **Campaign**: Dedicated section for major story arcs.
* **Zone Quests**: Grouped by map area with collapsible headers.
* **World Quests**: Includes expiration timers and progress bars.
* **Dungeons & Scenarios**: Dedicated Mythic+ (Keystone) timers and stage tracking.
* **Achievements**: Track your progress toward specific goals in real-time.

***

## Advanced Functionality

* **Secure Interaction**: Quest items are rendered as secure buttons, allowing you to use them directly from the tracker even during combat.
* **Modern API Support**: Updated for **Interface 12.0.0**, including support for Delves and PvP capture widgets.
* **Contextual Menus**: Right-click any objective to access a custom menu for sharing, abandoning, or stopping tracking.
* **Dynamic Scaling**: Easily adjust the width, scale, and maximum height of the tracker to fit your specific UI layout.

***

## Performance & Optimization

* **Low Memory Footprint**: Utilizes a sophisticated table pooling system for lines, bars, and buttons to minimize Garbage Collection churn and maintain high FPS.
* **Auto-Hide Features**: Can be configured to automatically hide during boss encounters to keep the screen clear for mechanics.
* **Custom Themes**: Uses a centralized asset system for consistent coloring and font management.

***

## Configuration & Notes

* **Modern Compatibility**: Designed for the latest version of the game with full support for new UI components.
* **Easy Access**: Managed through the standard Interface Options menu or through Ace3 configuration commands.

**Ascension Quest Tracker** es un reemplazo de alto rendimiento y minimalista para el rastreador de objetivos predeterminado de World of Warcraft. Este addon optimiza la experiencia de misiones al eliminar el desorden mientras proporciona una integración profunda con las características modernas del juego.

***

## Características Principales

* **Diseño Minimalista**: Una interfaz limpia y no intrusiva que reemplaza el voluminoso rastreador predeterminado con una lista elegante y organizada.
* **Clasificación Inteligente**: Las misiones se ordenan automáticamente por proximidad, asegurando que los objetivos más cercanos a tu ubicación actual estén siempre en la parte superior.
* **Integración con Super Track**: Soporte completo para el sistema nativo de enfoque "Super Track", con resaltado visual distintivo para tu objetivo principal.
* **Organización Modular**: Los objetivos se separan en categorías lógicas:
* **Campaña**: Sección dedicada para las tramas principales de la historia.
* **Misiones de Zona**: Agrupadas por área del mapa con encabezados colapsables.
* **Misiones de Mundo**: Incluye temporizadores de expiración y barras de progreso.
* **Mazmorras y Gestas**: Temporizadores dedicados para Mythic+ (Keystones) y seguimiento de etapas.
* **Logros**: Rastrea tu progreso hacia metas específicas en tiempo real.

***

## Funcionalidades Avanzadas

* **Interacción Segura**: Los objetos de misión se renderizan como botones seguros, permitiéndote usarlos directamente desde el rastreador incluso durante el combate.
* **Soporte de API Moderna**: Actualizado para la **Interfaz 12.0.0**, incluyendo soporte para Delves y widgets de captura de PvP.
* **Menús Contextuales**: Haz clic derecho en cualquier objetivo para acceder a un menú personalizado para compartir, abandonar o dejar de rastrear.
* **Escalado Dinámico**: Ajusta fácilmente el ancho, la escala y la altura máxima del rastreador para que se adapte al diseño específico de tu interfaz.

***

## Rendimiento y Optimización

* **Bajo Consumo de Memoria**: Utiliza un sofisticado sistema de table pooling para líneas, barras y botones para minimizar el Garbage Collection y mantener FPS altos.
* **Funciones de Auto-Hide**: Puede configurarse para ocultarse automáticamente durante encuentros con jefes para mantener la pantalla despejada para las mecánicas.
* **Temas Personalizados**: Utiliza un sistema de recursos centralizado para una gestión consistente de colores y fuentes.

***

## Configuración y Notas

* **Compatibilidad Moderna**: Diseñado para la versión más reciente del juego con soporte completo para los nuevos componentes de la interfaz.
* **Fácil Acceso**: Gestionado a través del menú estándar de Interface Options o mediante comandos de configuración de Ace3.
